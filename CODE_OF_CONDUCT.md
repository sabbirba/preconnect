# Code of Conduct

We are committed to keeping PreConnect a friendly, safe, and welcoming project for students, contributors, and maintainers.

This code of conduct applies to all project spaces, including:

- GitHub issues, pull requests, reviews, and discussions
- Release comments, changelogs, and contribution notes
- Any project-run chat or support channel
- Community-facing mentions of the project where participants are representing PreConnect

## Our Standards

We expect everyone to:

- Be respectful and considerate in all interactions.
- Assume good intent and stay open to feedback.
- Focus on the problem, not the person.
- Help make the project easier for new contributors to understand and join.
- Share context clearly when reporting bugs, requesting changes, or reviewing code.
- Respect privacy, consent, and safety when discussing student data, accounts, or screenshots.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, discrimination, personal attacks, or threats
- Hate speech or degrading language
- Doxxing, publishing private information, or sharing tokens, passwords, or private student data without consent
- Repeated disruption, trolling, or intentionally blocking collaboration
- Sexualized comments, coercion, or unwanted attention
- Misrepresenting another contributor’s work or identity

## Maintaining A Healthy Project

Maintainers may:

- Ask participants to edit or remove harmful content
- Mute, lock, or close a discussion if it becomes unsafe or unproductive
- Restrict participation in severe or repeated cases
- Refer urgent safety concerns to the appropriate reporting path

These actions are meant to protect the community and keep the project usable for everyone.

## Reporting

If you experience or witness unacceptable behavior, please report it through the private process listed in [SECURITY.md](SECURITY.md).

If the issue is not security-related, open a private discussion with the maintainers rather than escalating it publicly in the repo.

## Attribution

This project values the open-source community and the example set by widely used community standards. The intent of this document is to adapt those values to the PreConnect community and student-focused collaboration style.
