# Trademark Guidelines

The PreConnect name, logo, app icon, tagline, screenshots, and related brand assets are part of the project identity and are used to identify the PreConnect app and its official releases.

The PreConnect name is owned by the project contributors for project-identification purposes only. Open-source code in this repository does not grant permission to use the brand as if it were your own.

## Allowed Uses

You may use the name "PreConnect" when you are:

- Referring accurately to this project in reviews, articles, comparisons, tutorials, or citations
- Linking to the repository, release assets, or project documentation
- Describing compatibility, integration, or support for PreConnect in a factual way
- Showing screenshots of the app for reporting, education, or commentary

## Uses That Need Care

Please avoid brand use that could confuse people about who built or endorses the app.

That includes:

- Creating a fork, clone, or companion product with a name or logo that looks like official PreConnect branding
- Using the PreConnect name in an app store listing, social handle, website, or package name in a way that implies official status
- Modifying the logo or icon and presenting it as the official mark
- Reusing screenshots, mascots, or release art as if they were your own brand assets

## Not Allowed

You may not:

- Use the PreConnect name or logo in a way that suggests endorsement, affiliation, or partnership without permission
- Use confusingly similar names, logos, app icons, or branding for your own project or service
- Alter and redistribute the logo as your own brand identity
- Remove attribution from official artwork and present it as an independent brand

## Permissions

If you want to use the brand for partnership, promotional, or co-branded work, open an issue in this repository before publishing. Please describe:

- Where the mark will appear
- Whether it is a community, educational, or commercial use
- Whether the use is temporary or permanent
- Whether the user-facing text could imply official endorsement

## Notes

This policy is separate from the software license. The code is open source, but the brand remains a distinct identity that should not be reused in a misleading way.
