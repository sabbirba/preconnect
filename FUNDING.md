## What Support Helps With

Support is used to help cover the practical costs of keeping the project healthy, such as:

- Hosting and deployment infrastructure
- Domain and service costs
- Build and release maintenance
- Ongoing testing and bug fixing
- Small operational costs for student-run development

## Notes

- Support is optional. The app remains free to use.
- Donations do not create special access, private features, or priority support guarantees.
- Bug reports, feature requests, and code contributions are still welcome and valuable even if you do not donate.

## Community Help

If you cannot contribute financially, you can still help by:

- Filing clear bug reports
- Suggesting product improvements
- Testing release builds
- Sharing the project with other BRAC University students

Please create issues in the GitHub repo for product feedback.
